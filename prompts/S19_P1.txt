REFERENCE EXAMPLE - Stack Overflow: "Run a Stateless Application Using a Deployment"
Source: by Kubernetes Authors, https://kubernetes.io/docs/tasks/run-application/run-stateless-application-deployment/
Licensed CC BY 4.0.

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: nginx-deployment
spec:
  selector:
    matchLabels:
      app: nginx
  replicas: 2 # tells deployment to run 2 pods matching the template
  template:
    metadata:
      labels:
        app: nginx
    spec:
      containers:
      - name: nginx
        image: nginx:1.14.2
        ports:
        - containerPort: 80
```
